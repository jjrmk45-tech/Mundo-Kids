# Mundo-Kids
Mundo Kids é uma loja de brinquedos online desenvolvida com Django, criada para apresentar um catálogo de brinquedos com informações como nome, preço, estoque e faixa etária, incluindo páginas de listagem e detalhes dos produtos.
